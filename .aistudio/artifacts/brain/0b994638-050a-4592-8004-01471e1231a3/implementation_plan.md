# SoundShift 2.0 (4-Режимний Контролер Гучності та Профілів)

Масштабне оновлення системи керування звуковими профілями: 4-позиційний вертикальний тумблер (Вуличний / Денний / Беззвучний / Нічний), індивідуальні параметри гучності з точністю 1%, кнопка «Тест» для кожного аудіопотоку, виділений блок супер-підсилення (Audio Booster до 200%), системні тумблери (Mute, DND, Airplane, Reading, Dark mode тощо), розклад по днях тижня та підтримка Світлої/Темної тем.

### User Review & Critical Decisions

> [!IMPORTANT]
> Нижче наведено підтверджені вимоги та рішення для версії 2.0:

- **4 Режими та спеціальна палітра іконок**:
  - 🟠 **Вуличний (`Outdoor`)**: помаранчевий колір, іконка динаміка максимальної гучності (`volume_up`).
  - ⚪ **Денний (`Day`)**: чистий білий колір, іконка сонця (`wb_sunny`).
  - 🟢 **Беззвучний (`Silent`)**: насичений зелений колір, іконка перекресленого динаміка (`volume_off`).
  - 🔵 **Нічний (`Night`)**: блакитний колір, іконка місяця (`nightlight`).
- **Чиста шапка додатку**: Видалено бейдж активного режиму з правого верхнього кутка, додано кнопку швидкого перемикання теми (Світла / Темна / Системна).
- **Індивідуальні налаштування під кожен режим**: При перемиканні режиму тумблером унизу автоматично відображаються його власні параметри (рівні звуку та увімкнені системні тумблери).
- **Точність 1% та кнопки «Тест»**: Плавні повзунки з точним кроком 1% та кнопка прослуховування дефолтного системного рингтону/звуку сповіщення/медіа поруч із кожним повзунком.
- **Окремий блок «Super Boost (Audio Booster до 200%)»**: Виділена частина інтерфейсу з візуальним неоновим індикатором додаткового програмного посилення.
- **Швидкі системні перемикачі для кожного профілю**: Mute, DND, Vibrate, Dark mode, Auto brightness, Battery saver, Reading mode, Airplane mode.
- **Розклад та сценарії по днях тижня**: Опціональне налаштування автоматичного вмикання профілю за часом та вибором днів (Пн–Нд).
- **Швидке керування у сповіщеннях**: Оновлена панель у шторці з 4 прямими кнопками для кожного режиму.

### 1. Overview & Core Concept

- **What It Does**: SoundShift перетворюється на повнофункціональний центр керування аудіопрофілями та оточенням смартфона. Користувач одним рухом 4-позиційного тумблера переводить пристрій у потрібний стан — від нічного відпочинку з приглушеним світлом до надгучного вуличного режиму.
- **Target Audience**: Користувачі, яким потрібен чіткий контроль над звуком, вібрацією, яскравістю та нічним режимом за розкладом чи вручну.
- **Key Value**: Повна автоматизація звукового середовища без щоденного ручного підлаштовування кожного окремого повзунка.

---

### 2. User Experience & Visual Design

- **Key User Flows**:
  1. *Перемикання 4-позиційного тумблера*: Плавний фізичний перехід між положеннями (Вулиця 🟠 -> День ⚪ -> Беззвучний 🟢 -> Ніч 🔵) із тактильним вібровідгуком.
  2. *Індивідуальний екран налаштувань режиму*: Нижче тумблера відкриваються параметри саме для вибраного режиму:
     - 3 повзунки гучності (Дзвінки, Сповіщення, Медіа) з кроком 1% та кнопками «▶ Тест» (програє системний звук `RingtoneManager`).
     - Блок перемикачів середовища (Mute, DND, Вібрація, Темна тема, Автояскравість тощо).
     - Розклад активності за днями тижня та часом.
  3. *Блок Audio Booster*: Яскраво виділена неонова панель надгучності (100%–200%) з підсиленням звуку для шумних місць.
  4. *Перемикання теми*: Кнопка сонця/місяця у верхньому правому кутку шапки для миттєвої зміни Світла ↔ Темна.

- **Visual Identity & Theme**:
  - *Денна тема*: Преміальний світлий мінімалізм (ніжний бузковий серпанок `#F8F5FC`, чистий білий `#FFFFFF`, контрастні темні шрифти `#1A1528`).
  - *Нічна тема*: Глибокий аметистово-вугільний фон (`#120F1D`) з бузковими акцентами та сяючими статусними маркерами.
  - *Кольори іконок режимів*:
    - Вуличний: Vibrant Orange (`#FF9800`)
    - Денний: Pure White (`#FFFFFF`) / Dark Plum в світлій темі (`#382458`)
    - Беззвучний: Electric Emerald Green (`#4CAF50`)
    - Нічний: Sky Blue / Cyan (`#00B0FF`)

### 3. Key Product Decisions & Trade-Offs

- **Decision 1: Збереження незалежних профілів для всіх 4 режимів**:
  - *Підхід*: Для кожного з 4 режимів зберігається окремий об'єкт `ProfileSettings` (гучності, стан DND, Mute, Vibrate, налаштування розкладу).
  - *Переваги*: При поверненні до будь-якого режиму користувач отримує саме той набір налаштувань, який він налаштував раніше.
- **Decision 2: Безпечне відтворення тестових звуків через RingtoneManager**:
  - *Підхід*: Використання стандартного `RingtoneManager` Android для отримання `TYPE_RINGTONE`, `TYPE_NOTIFICATION` та короткого медіа-тону, що зупиняється через 2.5 секунди.
  - *Переваги*: Користувач чує саме свої рідні звуки телефону перед збереженням.
- **Decision 3: Реалізація системних тумблерів (Mute, DND, Dark mode тощо)**:
  - *Підхід*: Пряме застосування системних параметрів через `AudioManager` та `NotificationManager`, а для системних захищених режимів (Airplane mode, Reading mode) — швидке відкриття відповідного діалогу або панелі системних налаштувань з чітким зворотним зв'язком.
